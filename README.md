# crab-AI · 人类的第二个大脑

一个跑在单个 HTML 文件里的记忆闭环原型：把日常对话拆成可审计的事实条目，回答前先召回记忆，再由规则层约束输出。

> 当前主版本：`crabAI-记忆闭环原型-R2.html`（单文件，双击即用，无外部依赖）

---

## 一、它是什么，不是什么

**是**：记忆写入与召回的原型工具。流程为 抽取 → 人工确认 → 入库 → 召回 → 回答，每一步都有可见的记录与审计。

**不是**：不是聊天陪伴产品，不做情绪抚慰，不替使用者下结论；也不追求“像人”的说话方式。

---

## 二、三个核心机制

| 机制 | 做法 | 目的 |
|---|---|---|
| 推断不入库 | 写入前做 R22 三列转换：事实 / 情绪标记 / 推断句（带置信度） | 防止“她一定是不在乎我了”这类猜测变成永久记忆 |
| 写入分型 + 可撤销快照 | `planWrite` 判定 new / merge / update / supersede / noop，提交时返回 ops；撤销按 ops 还原被合并或取代的旧条目 | 撤销不删老记录，避免误删既有记忆 |
| 规则层 L0 审计 | 5 条默认规则 + 禁用话术扫描；回答命中即按规则重写一次，仍命中则明确标注“未过审” | 让“不安慰、不替人下结论”成为可检查的约束，而不是一句口号 |

---

## 三、快速开始

1. 下载并双击 `crabAI-记忆闭环原型-R2.html`（Edge / Chrome 均可，无需服务器）
2. 进入「设置」，填入 DeepSeek API Key（模型默认 `deepseek-chat`）
3. 点「保存」→「测试连接」
4. 在对话里发一句话：**先流式出回答**，回答结束后才弹出记忆候选；勾选并确认后才入库

未填 Key 时一切照旧可用，回答由本地规则引擎生成（六段结构：事实 / 你加的情绪与推断 / 其他解读 / 判断依据 / 选项与代价 / 建议）。

## 四、自检与演示参数

在文件地址后追加查询参数即可进入对应模式：

| 参数 | 作用 |
|---|---|
| `?selftest=1` | 跑 42 项内置断言，全过则页面标题为 `SELFTEST_PASS` |
| `?demo=flow` | 完整发送流程（先回答、后拆解入库），标题显示 `FLOW_OK` |
| `?demo=reply` | 本地引擎的六段回答 |
| `?demo=sheet` / `tree` / `graph` / `rules` / `export` | 分别预览候选卡、记忆树、图谱、规则页、导出页 |

## 五、技术栈

- 单 HTML：内联 CSS 与 JS，无 CDN、无外链脚本
- 存储：IndexedDB 库 `crabai` v1（`facts` / `meta`），失败时回退 localStorage
- 模型调用：`POST {base}/v1/chat/completions`，`stream: true`，按 SSE 逐块渲染
- 检索：bigram 重叠系数 + 关键词加权，token 预算 600
- 导出：JSON（`rules` + `facts`，不含 API Key）与 Markdown（按记忆树分组）

---

## 六、数据与隐私

- API Key 只保存在本机浏览器，不写入导出文件，也不进版本库
- 全部数据在本机，删除浏览器数据即清空
- 导出 JSON 可用于备份；Markdown 可直接放入 Obsidian

---

## 七、已知限制

- 只有导出，没有导入
- 检索基于字面相似度，不是向量检索；换一种说法可能召回不到
- 单用户、单设备；跨设备需手动搬 JSON
- 中文按规则切句，长句或口语化表达可能漏抽
- 回答质量依赖模型；未配置 Key 时只有模板化输出
